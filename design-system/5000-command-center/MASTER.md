## 1. ตัวตนของแบรนด์

- **อารมณ์:** แก๊งเกม ดุดัน กลางคืน — พื้นดำเกือบสนิท แดงโลโก้ 5000 ใช้น้อยแต่ชัด
- **สไตล์:** Dark + frosted glass + brush (ลายแปรงแห้ง) + ฉาก 3D ด้านหลัง
- **ความหนาแน่น:** Dashboard (density 8/10) — ข้อมูลเยอะ แต่ต้องอ่านง่ายบนมือถือ
- **ห้าม:** ธีมสว่าง, ม่วงนีออน, ไล่สีรุ้ง, อีโมจิเป็นไอคอน

## 2. สี

ใช้ token เสมอ ห้ามฝัง hex ในคอมโพเนนต์
สีโปร่งใส ใช้ `color-mix(in srgb, var(--ui-red) 35%, transparent)` แทน `rgba(...)`

| บทบาท | Token | ค่า | ใช้กับ |
|---|---|---|---|
| พื้นหลังหน้า | `--ui-bg` | `#08080a` | body |
| การ์ดทึบ | `--ui-card` | `#111114` | dialog, popover |
| การ์ดกระจก | `--ui-glass` | `rgba(17,17,20,.9)` (`.93` ตอนเปิดฉาก 3D) | panel, tile, topbar stat |
| ยกขึ้น | `--ui-raised` | `#1d1d23` | ปุ่ม/แท็บที่เลือก |
| เส้น | `--ui-line` / `--ui-line-strong` | ขาว 7.5% / 13% | ขอบการ์ด / ขอบ input |
| ตัวหนังสือหลัก | `--ui-text` | `#f4f4f6` (17:1) | หัวข้อ เนื้อหา |
| ตัวหนังสือรอง | `--ui-text-2` | `#c5c5ce` (10.6:1) | คำอธิบาย label |
| ตัวหนังสือจาง | `--ui-text-3` | `#9b9ba8` (6.9:1) | meta, placeholder — ห้ามใช้กับข้อความสำคัญ |
| แดงแบรนด์ | `--ui-red` | `#e3141b` | ไอคอน เส้น แถบ ตัวเลขใหญ่ |
| แดงปุ่ม | `--ui-red-fill` | `#d10f16` (5.4:1 กับขาว) | พื้นปุ่มหลัก badge |
| แดงตัวหนังสือ | `--ui-red-light` | `#ff6b70` (6.1:1) | ตัวหนังสือแดงเล็กบนพื้นดำ |
| สำเร็จ | `--ui-green` | `#3ddc84` | ผ่านแล้ว ออนไลน์ |
| รอ/เตือน | `--ui-amber` | `#ffb547` | รอตรวจ ใกล้หมดเวลา |
| เหรียญ | `--ui-gold` / `--ui-silver` / `--ui-bronze` | | อันดับ 1–3 |
| Discord | `--ui-discord` | `#5865f2` | ปุ่ม/ป้าย Discord เท่านั้น |

**กฎ**
- ปุ่มหลักต่อหน้าจอมีได้ **ปุ่มเดียว** ที่เป็นแดงทึบ (`ui-btn--primary`)
- สถานะห้ามบอกด้วยสีอย่างเดียว — ต้องมีไอคอนหรือคำด้วย (✓ ผ่าน / นาฬิกา รอตรวจ / ✕ ไม่ผ่าน)
- ข้อความบนพื้นการ์ดต้องได้ 4.5:1 ขึ้นไป; ถ้าวางบนฉาก 3D ต้องอยู่บนการ์ดทึบ ≥ 90%

## 3. ตัวอักษร

| บทบาท | ฟอนต์ | Token |
|---|---|---|
| หัวข้อ ตัวเลข | Kanit heavy italic (`--font-display`) | |
| เนื้อหา | IBM Plex Sans Thai (`--font-body`) | |
| ตัวเลขแบบลายแปรง | Permanent Marker (`--font-brush`) | ตัวเลขใหญ่บน podium / stat |

**สเกล (px):** `--ui-fs-12` · 13 · 14 · 15 · 16 · 18 · 20 · 22 · 24 · 28 · 32 · 40

| ใช้กับ | ขนาด |
|---|---|
| badge, eyebrow, meta | 12–13 |
| เนื้อหา, label, ปุ่ม | 14 |
| เนื้อหาเน้น, ปุ่มใหญ่ | 15–16 |
| หัวข้อการ์ด | 18–20 |
| หัวข้อหน้า (มือถือ / เดสก์ท็อป) | 21 / 28 |
| ตัวเลขใหญ่, หัวภารกิจ | 24–40 |

**กฎ**
- ห้ามต่ำกว่า 12px
- เนื้อหาบรรทัดยาวใช้ line-height 1.5–1.6
- ตัวเลขในตาราง/นาฬิกาใช้ `font-variant-numeric: tabular-nums`
- หัวข้อสั้นใช้ `text-wrap: balance`; วันที่ห่อด้วย `white-space: nowrap` ไม่ให้ขาดกลางวันที่

## 4. ระยะห่าง เลย์เอาต์

- ระบบ 4px: 4 · 8 · 12 · 16 · 20 · 24 · 32
- ช่องว่างระหว่างการ์ด 20px (มือถือ 14–16px), padding การ์ด 16–20px (มือถือ 14–18px)
- Breakpoint: `<640` มือถือ · `<1024` แท็บเล็ต (แถบล่าง) · `≥1024` sidebar · `≥1280` + แถบขวา
- คอลัมน์กลางใช้ container query (`.main-col`) — การ์ดภารกิจแบ่ง 2 คอลัมน์เมื่อกว้าง ≥ 960px เท่านั้น
- ห้ามมี scroll แนวนอนบนมือถือ; เนื้อหาต้องเว้นที่ให้แถบล่าง (96px + safe area)

## 5. รูปทรง เงา

**มุมโค้ง:** `--ui-radius-2xs` 6 · `xs` 10 · `sm` 12 (ปุ่ม input) · `md` 14 · `lg` 16 · `--ui-radius` 18 (การ์ด) · `2xl` 22 · `3xl` 26 · `pill` 999

**เงา:** `--ui-shadow` สำหรับการ์ดทุกใบ; ปุ่มแดงมีเงาแดงเรือง; อย่าสร้างเงาค่าใหม่เอง

**Blur:** `--ui-blur` ใช้กับการ์ดที่วางบนฉาก 3D และพื้นหลัง dialog เท่านั้น

## 6. คอมโพเนนต์ (อยู่ใน `app/ui.tsx` และ `app/styles/blocks.css`)

| คอมโพเนนต์ | คลาส | สเปก |
|---|---|---|
| ปุ่ม | `ui-btn` + `--primary` / `--ghost` / `--ok` / `--sm` / `--lg` / `--block` | สูง ≥ 42px (`--sm` 34px, จอสัมผัส 40px), กดแล้วย่อ 0.98 |
| ปุ่มไอคอน | `icon-btn` | 40px (จอสัมผัส 44px) ต้องมี `aria-label` |
| การ์ด | `Panel` (`ui-panel`) | กระจก 90%, radius 18, หัวการ์ดมีลายแปรงใต้ชื่อ |
| แถว | `Row` | leading / title / subtitle / trailing; สูงเท่ากันทุกแถว |
| แท็บ | `Segmented` | เกิน 5 แท็บให้ตกบรรทัด (`.admin-tabs`) ไม่ซ่อนเกินขอบ |
| ช่องกรอก | `ui-input` ใน `form-field` | สูง ≥ 44px, **ต้องมี label ที่มองเห็น** (placeholder เป็นตัวอย่างเท่านั้น) |
| คำใบ้ใต้ปุ่ม | `form-hint` | บอกเหตุผลเมื่อปุ่มกดไม่ได้ |
| Dialog | `ConfirmDialog`, `PromptDialog` | ปิดได้ด้วยปุ่ม + Esc เสมอ |
| ว่าง | `EmptyState` | มีภาพ 3D + บอกว่าทำอะไรต่อ |
| สถานะ | `status-pill`, `round-pill` | สี + ไอคอน/คำ |

## 7. การเคลื่อนไหว

- Hover/สถานะ: 150ms ease · กด: 100ms · การ์ดเข้า: 500–600ms ease-out
- ใช้แค่ `transform` / `opacity` / `filter`
- เคารพ `prefers-reduced-motion` เสมอ (มีอยู่แล้วใน `motion.css`)
- ฉาก 3D มีสามโหมด เคลื่อนไหว / นิ่ง / ปิด — ทุกหน้าต้องใช้งานได้ครบเมื่อปิดฉาก

## 8. การโต้ตอบและการตอบสนอง

- ปุ่มที่ทำงาน async ต้องปิดระหว่างรอ (`busy`)
- งานที่ทำซ้ำเร็ว ๆ (ตรวจหลักฐาน) ห้ามรอโหลดข้อมูลใหม่ทั้งหน้า — บันทึกแล้วไปต่อทันที รีเฟรชเบื้องหลัง
- งานเสริมฝั่งเซิร์ฟเวอร์ (การ์ด Discord, ลบรูป) ใช้ `after()` ไม่ให้ผู้ใช้รอ
- ยืนยันก่อนทำสิ่งที่ย้อนไม่ได้ (ยุบทีม, นำสมาชิกออก, ส่งหลักฐาน)
- ข้อความแจ้งเตือน (toast) ไม่ขโมย focus และหายเอง

## 9. ภาษา

- ใช้คำว่า **ทีม** (ไม่ใช่ปาร์ตี้), **หลักฐาน**, **แต้ม**, **รอบ**, **แอร์ดรอป**, **งัดร้าน**, **ลูป**
- ข้อความ error บอกเหตุ + วิธีแก้ ("รูปใหญ่เกินไป ลองใช้รูปที่เล็กลงหรือแคปหน้าจอใหม่")

## 10. ห้ามทำ

- ❌ ฝัง hex/rgba ในคอมโพเนนต์ — ใช้ token
- ❌ ขนาดตัวอักษรหรือมุมโค้งนอกสเกล
- ❌ อีโมจิเป็นไอคอน — ใช้ lucide-react
- ❌ ตัวหนังสือวางบนฉาก 3D โดยตรง
- ❌ บอกสถานะด้วยสีอย่างเดียว
- ❌ ช่องกรอกที่มีแค่ placeholder
- ❌ แท็บหรือเนื้อหาที่ซ่อนเกินขอบโดยไม่มีสัญญาณ
- ❌ ลบ focus ring

## 11. เช็กลิสต์ก่อนส่งงาน

- [ ] ใช้ token ครบ ไม่มีสี/ขนาดฝังใหม่
- [ ] คอนทราสต์ตัวหนังสือ ≥ 4.5:1
- [ ] ปุ่มบนจอสัมผัส ≥ 44px, ห่างกัน ≥ 8px
- [ ] ปุ่มไอคอนมี `aria-label`; ช่องกรอกมี label
- [ ] มี focus ring ตอนใช้คีย์บอร์ด
- [ ] ทดสอบที่ 390 · 768 · 1024 · 1440px ไม่มี scroll แนวนอน
- [ ] ปิดฉาก 3D แล้วยังใช้งานได้; reduced-motion ไม่มีแอนิเมชันค้าง
- [ ] สถานะมีไอคอน/คำ ไม่ใช่สีอย่างเดียว
- [ ] หน้าว่างมีคำแนะนำว่าทำอะไรต่อ
