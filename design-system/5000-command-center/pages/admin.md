# หน้า "จัดการแก๊ง" — กฎเฉพาะหน้า

ใช้แทน MASTER.md เฉพาะเรื่องที่เขียนไว้ที่นี่ เรื่องอื่นใช้ตาม MASTER.md

- **ความหนาแน่น:** สูงสุดของเว็บ (density 9/10) — แถวเตี้ยได้ แต่ปุ่มในแถวยัง ≥ 34px (จอสัมผัส ≥ 40px)
- **แท็บ:** 8 แท็บ ตกบรรทัดได้ (`.admin-tabs`) เรียงจากงานที่ทำบ่อยสุด: รอตรวจ → เช็กชื่อ → สมาชิก → ทีม → แต้ม → ประวัติแก้แต้ม → การลา → แอดมิน
- **ปุ่มหลักของหน้า:** "ตรวจทีละรายการ" เป็นปุ่มแดงปุ่มเดียว ปุ่มในแต่ละแถวเป็น ghost
- **หน้าตรวจหลักฐาน (`ReviewDialog`):**
  - รูปใหญ่ก่อน แล้วค่อยรายละเอียด แล้วปุ่ม ผ่าน/ไม่ผ่าน
  - ต้องตรวจได้ด้วยคีย์บอร์ด (A / R / ← →) และปัดรูปบนมือถือ
  - กดแล้วไปรายการถัดไป **ทันที** หลังบันทึก — ห้ามรอโหลดข้อมูลใหม่
  - โหลดรูปถัดไปล่วงหน้าเสมอ
  - ไม่ถามยืนยันซ้ำต่อรายการ (การกดคือการยืนยัน)
- **ตัวเลขสถิติ:** tabular-nums เสมอ
