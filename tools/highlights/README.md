# หาช่วงเด็ดจากไลฟ์ (find_highlights)

สคริปต์นี้อ่านวิดีโอไลฟ์ยาว ๆ (เช่น `lung-a-live.mp4` ~5 GB) แล้วเสนอ **ผู้เข้ารอบช่วงเด็ด 8–10 ช่วง**
พร้อมเวลาเริ่ม–จบ เหตุผล และข้อความที่พูดในช่วงนั้น ให้คุณเลือกก่อนตัดจริง
**ไม่สร้างซับ** ข้อความถอดเสียงใช้ช่วยหาช่วงเด็ดเท่านั้น

ใช้ Python มาตรฐานล้วน ๆ ไม่ต้องติดตั้งไลบรารีเพิ่ม ยกเว้นถ้าอยากให้ถอดเสียงไทยให้ (ดูด้านล่าง)

## สิ่งที่ต้องมี
- Python 3.10+ และ ffmpeg (มีแล้วถ้าโหลดคลิปด้วย yt-dlp ได้: `winget install Gyan.FFmpeg`)
- ถ้าจะให้ถอดเสียงเอง: `pip install faster-whisper`

## วิธีรัน (PowerShell บน Windows)
ไปที่โฟลเดอร์ที่มีไฟล์วิดีโอ แล้วรัน (แก้พาธ `tools\highlights` ให้ตรงกับที่ดึง repo ลงมา)

```
# แบบเร็ว: ใช้เสียง+ภาพอย่างเดียว ไม่ถอดเสียง
python tools\highlights\find_highlights.py lung-a-live.mp4 --no-transcribe --out highlights_out

# แบบเต็ม: ถอดเสียงไทยด้วย whisper ด้วย (ช้ากว่ามากกับไลฟ์ยาว ๆ)
python tools\highlights\find_highlights.py lung-a-live.mp4 --out highlights_out --model small

# ถ้ามีข้อความถอดเสียงอยู่แล้ว (.json หรือ .srt) ใช้ไฟล์นั้นแทน
python tools\highlights\find_highlights.py lung-a-live.mp4 --transcript transcript.json
```

ใช้ `python` ธรรมดา ไม่ใส่ `-I` เพราะ `-I` จะมองไม่เห็นแพ็กเกจที่ติดตั้งแบบ `--user`

ผลลัพธ์ในโฟลเดอร์ `highlights_out`:
- `candidates.md` อ่านง่าย: ตารางผู้เข้ารอบ + รายละเอียด + คำสั่งตัดตัวอย่างสั้น ๆ ไว้ฟังก่อน
- `candidates.json` สำหรับขั้นตอนประกอบคลิปต่อ
- `transcript.json` (ถ้าถอดเสียงเอง) รันซ้ำจะใช้ไฟล์นี้ ไม่ถอดใหม่ ใส่ `--retranscribe` ถ้าอยากถอดใหม่

## ให้คะแนนยังไง
ทุกหน้าต่าง 5 วินาที รวมสัญญาณ 4 อย่าง (ถ้าไม่มีข้อความถอดเสียง จะใช้เฉพาะเสียงกับภาพ)

| สัญญาณ | วัดจาก | น้ำหนัก |
|---|---|---|
| เสียงดังขึ้นผิดปกติ | ความดังเทียบกับช่วงรอบ ๆ ±1 นาที (มุก/เสียงหัวเราะ/ตื่นเต้น) | 0.35 |
| พูดถี่ | จำนวนตัวอักษรต่อวินาทีจากข้อความถอดเสียง | 0.20 |
| คำกระตุ้น | ฮ่า, 555, โอ้โห, ว้าว, ชนะ ฯลฯ (ตั้งเองได้ด้วย `--keywords "คำ1,คำ2"`) | 0.25 |
| ภาพเปลี่ยนฉาก | คะแนนเปลี่ยนฉากที่ keyframe (ช่วงเกม/จังหวะพีค) | 0.20 |

จากนั้นคัดช่วงคะแนนสูงที่ไม่ซ้อนกัน ยาวเป้าหมาย ~20 วินาที (`--clip-len`) ไม่เกิน 35 วินาที (`--max-len`)
ถ้ามีข้อความถอดเสียง จุดเริ่ม–จบจะลงที่ขอบประโยค ถ้าไม่มีจะลงที่ขอบช่วงเงียบแทน
และแนะนำช่วงเงียบเกิน ~1 วินาทีที่ควรตัดออก (`cut_silences`)

## ข้อจำกัด (อ่านก่อนเชื่อผล)
- **นี่คือตัวช่วยคัด ไม่ใช่ตัวตัดสิน** ต้องฟังตัวอย่างก่อนเลือกเสมอ
- เสียงหัวเราะวัดจากพลังงานเสียง เสียงเกม/เพลงดัง ๆ ก็ทำให้คะแนนขึ้นได้
- เกณฑ์ "แชตคึกคัก" ทำอัตโนมัติไม่ได้ ถ้าแชตไม่อยู่ในภาพ ต้องดูเอง
- รายการคำกระตุ้นเริ่มต้นเป็นการเดา ปรับให้ตรงกับคำที่ลุงเอพูดจริงได้
- ทดสอบแล้วกับวิดีโอสังเคราะห์เท่านั้น (`python selftest.py`) **ยังไม่เคยรันกับไฟล์จริงของคุณ**
  และส่วนถอดเสียง whisper ยังไม่ได้ทดสอบบนคลาวด์ (โหลดโมเดลไม่ได้)
- ถ้าวิเคราะห์ภาพช้าเกินไป (ไฟล์ AV1 1080p ยาว ๆ) ใส่ `--no-scene` เพื่อข้ามเกณฑ์ภาพ
- ถ้าถอดเสียงช้า: ใช้ `--model small` (ค่าเริ่มต้น) หรือถ้ามีการ์ดจอ NVIDIA ใช้ `--device cuda`
  โมเดล `medium`/`large-v3` แม่นกว่าแต่ช้ากว่ามากบน CPU

## ทดสอบสคริปต์
```
python tools\highlights\selftest.py
```
สร้างวิดีโอจำลอง 180 วินาทีแล้วเช็กว่าช่วงเด็ดที่ฝังไว้ถูกจัดอันดับ 1–2 และจุดตัดลงขอบประโยค

## ขั้นต่อไปหลังได้รายการ
1. ฟังตัวอย่างช่วงที่สนใจ (คำสั่ง `ffmpeg ... preview_XX.mp4` ใน `candidates.md`)
2. เลือก 4–6 ช่วง + ลำดับ (ถ้าจะลง Shorts ความยาวรวมต้องไม่เกิน 60 วินาที)
3. เลือกการจัดเฟรม 9:16 (ครอปกลาง หรือซ้อนบน–ล่าง) แล้วประกอบใน HyperFrames
   (ไม่ใส่ซับ/หัวข้อ/ชื่อช่อง/เพลง)
